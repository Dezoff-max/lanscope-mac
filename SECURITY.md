# Security Policy

## Supported Versions

LanScope Mac is currently in MVP development. Security fixes are applied to the latest public version.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory or by contacting the repository owner.

Do not publish exploit details for unresolved issues.

## Scope

LanScope Mac is designed for local network administration. Use it only on networks you own or are authorized to administer.

The app does not use private macOS APIs, does not require root privileges for MVP scanning, and does not send scan data to external servers.
